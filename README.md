# Calculator – CodeAlpha Internship Task 2

## About the Project

This is a simple and responsive Calculator Web Application built as part of my **CodeAlpha Frontend Development Internship**.

The calculator performs basic mathematical operations such as addition, subtraction, multiplication, and division. It has a clean and user-friendly interface.

## Features

- Addition (+)
- Subtraction (−)
- Multiplication (×)
- Division (÷)
- Clear (AC) button to reset the calculation
- Backspace button to remove the last entered character
- Displays the calculation result
- Keyboard support for easy use
- Simple and responsive design

## Technologies Used

- **HTML5** – To create the calculator structure.
- **CSS3** – To style the calculator and buttons.
- **JavaScript** – To perform calculations and handle button clicks.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the `index.html` file in your browser.
4. Start using the calculator by clicking the buttons.
5. You can also use your keyboard to enter calculations.
